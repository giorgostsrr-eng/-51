# CareBridge | Ομάδα 51

## Η ιδέα μας

Είμαστε η Ομάδα 51 και φτιάξαμε το CareBridge ως prototype για μια απλή ιδέα: να μπορούν ηλικιωμένοι να ζητούν καθημερινή βοήθεια από εθελοντές της περιοχής τους. Ένα αίτημα μπορεί να αφορά, για παράδειγμα, ψώνια, συνοδεία σε ραντεβού, βοήθεια με την τεχνολογία ή λίγη παρέα.

Θέλαμε να δείξουμε τη διαδικασία και από τις δύο πλευρές. Το άτομο που ζητά βοήθεια μπορεί να επιλέξει μία ή περισσότερες δραστηριότητες, να ορίσει ημέρα και ώρα και να προσθέσει σημειώσεις. Ο εθελοντής βλέπει το αίτημα, μπορεί να διαβάσει τις λεπτομέρειες και να το αποδεχτεί. Στη συνέχεια, η πρόοδος της επίσκεψης εμφανίζεται και στις δύο προβολές.

## Τι περιλαμβάνει

- Δύο demo ρόλους: άτομο που ζητά βοήθεια και εθελοντής.
- Δημιουργία αιτήματος με πολλαπλές δραστηριότητες, ημερομηνία, ώρα και σημειώσεις.
- Ροή κατάστασης επίσκεψης: νέο αίτημα, αποδοχή, καθ' οδόν και ολοκλήρωση.
- Προβολές προσεχών και ολοκληρωμένων επισκέψεων και για τους δύο ρόλους.
- Απλή συνομιλία με έτοιμες γρήγορες απαντήσεις.
- Μεγαλύτερο μέγεθος γραμματοσειράς, βαθμολογία επίσκεψης και ενδεικτικό παράθυρο έκτακτης ανάγκης.

## Η ιδέα μας για τις προτάσεις

Στην τελική ιδέα, το σύστημα θα προτείνει στους εθελοντές ανοιχτά αιτήματα που ταιριάζουν καλύτερα σε αυτούς. Θα λαμβάνει υπόψη το είδος της δραστηριότητας και τις δεξιότητες ή τα ενδιαφέροντα του εθελοντή, την απόσταση από το σημείο της επίσκεψης και το αν είναι διαθέσιμος την ημέρα και ώρα που ζητήθηκαν. Με βάση αυτά τα στοιχεία, τα πιο σχετικά αιτήματα θα εμφανίζονται πρώτα.

Δεν σχεδιάζουμε να προβλέπουμε προσωπικά ή ιατρικά στοιχεία, ούτε να αποδεχόμαστε αιτήματα αυτόματα. Η πρόταση θα είναι απλώς ένας τρόπος να βρίσκει ο εθελοντής πιο εύκολα αιτήματα που μπορεί να αναλάβει.

Αυτή η λειτουργία δεν έχει υλοποιηθεί ακόμα στο demo. Οι ενδείξεις «Smart Feed», «Best Choice» και οι λόγοι αντιστοίχισης εμφανίζονται ενδεικτικά και δεν υπολογίζονται δυναμικά από τα στοιχεία του εθελοντή.

## Πώς να δοκιμάσετε το demo

1. Εκκινήστε την εφαρμογή και επιλέξτε «I need help».
2. Επιλέξτε μία ή περισσότερες δραστηριότητες, πατήστε «Find Student» και συμπληρώστε τα στοιχεία της επίσκεψης.
3. Πατήστε «Post Visit Request» για να δημιουργηθεί το αίτημα.
4. Επιστρέψτε στην αρχική οθόνη και αλλάξτε σε «I want to help» για να δείτε το αίτημα ως εθελοντής.
5. Αποδεχτείτε το αίτημα και χρησιμοποιήστε τις ενέργειες της επίσκεψης για να αλλάξετε την κατάστασή της. Έπειτα, επιστρέψτε στον πρώτο ρόλο για να δείτε την ενημέρωση.

## Εκτέλεση τοπικά

Χρειάζονται Node.js 20.19 ή νεότερο και npm. Αφού κλωνοποιήσετε το repository, εκτελέστε:

```bash
npm install
npm run dev
```

Ανοίξτε στον browser τη διεύθυνση που θα εμφανιστεί στο terminal, συνήθως `http://localhost:5173`. Για να σταματήσετε τον server, πατήστε `Ctrl+C`.

## Τεχνολογίες

Το prototype υλοποιήθηκε με React, TypeScript και Vite. Για τα εικονίδια χρησιμοποιήσαμε το Lucide React.

## Περιορισμοί του prototype

Η εφαρμογή είναι demo και δεν έχει συνδεθεί με backend. Τα αιτήματα, τα μηνύματα και οι αλλαγές κατάστασης κρατιούνται προσωρινά στη μνήμη της εφαρμογής και χάνονται όταν γίνει ανανέωση της σελίδας. Οι δύο ρόλοι χρησιμοποιούνται στην ίδια εφαρμογή για την παρουσίαση της ροής· δεν υπάρχει συγχρονισμός ανάμεσα σε διαφορετικές συσκευές ή πραγματικούς λογαριασμούς. Η λειτουργία προτάσεων δεν υπολογίζεται δυναμικά και η λειτουργία έκτακτης ανάγκης δεν επικοινωνεί με εξωτερικές υπηρεσίες.
