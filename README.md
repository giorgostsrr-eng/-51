# CareBridge (Ομάδα 51) 🤝

Το **CareBridge** είναι μια εφαρμογή κοινοτικής φροντίδας (mobile-first prototype) που συνδέει ηλικιωμένους με μαθητές και φοιτητές εθελοντές της γειτονιάς. Στόχος της είναι να προσφέρει βοήθεια σε απλά καθημερινά πράγματα — όπως ψώνια από το σουπερμάρκετ, συνοδεία σε γιατρούς ή φαρμακεία, βοήθεια με την τεχνολογία, αλλά και συντροφικότητα (βόλτα, καφές, κουβέντα).

---

## 📱 Χαρακτηριστικά & Διαδραστικές Λειτουργίες (Features)

### 1. 🔄 Εναλλαγή Ρόλων (Senior & Student Assistant View)
- **Role Switcher:** Πλήρης δυνατότητα εναλλαγής μεταξύ των δύο προφίλ (Ηλικιωμένος / Εθελοντής Μαθητής) για πλήρη επίδειξη (demo) της ροής της εφαρμογής.

### 2. 📅 Οδηγός Αιτήματος 2 Βημάτων (Senior Booking Wizard)
- **Επιλογή Υπηρεσίας:** Κάρτες επιλογής καθημερινής ανάγκης (Ψώνια / Σουπερμάρκετ, Συνοδεία σε Γιατρό, Συντροφικότητα & Καφές, Τεχνική Υποστήριξη, Μικροεργασίες).
- **Οριζόντιο Ημερολόγιο (Date Strip):** Ομαλή οριζόντια κύλιση (scroll) για εύκολη επιλογή ημέρας.
- **Interactive Time Chips:** Επιλογή ώρας με διαδραστικά κουμπιά.

### 3. 🎯 Σύστημα Συστάσεων (Smart Feed & Recommendation System)
- **Recommendation Engine:** Σύστημα σύστασης (Smart Match) που προτείνει στον εθελοντή κατάλληλα αιτήματα με βάση ενδεικτικά στοιχεία όπως η απόσταση, οι δεξιότητες και η διαθεσιμότητα.
- **Best Choice Badge:** Ειδική σήμανση στο αίτημα που προτείνεται ως καλύτερη επιλογή.
- **Request Details Modal:** Pop-up παράθυρο για προεπισκόπηση των λεπτομερειών και των σημειώσεων του ηλικιωμένου πριν την αποδοχή της επίσκεψης.

### 4. 🚗 Tracker Προόδου Επίσκεψης (Visit Progress Tracker)
- **Visual Progress Bar:** Παρακολούθηση της επίσκεψης σε τέσσερα στάδια (*Requested ➔ Student Found ➔ On the way 🚗 ➔ Done*).
- **Dynamic In-App Updates:** Οι νέες αιτήσεις και οι αλλαγές κατάστασης εμφανίζονται στις αντίστοιχες προβολές κατά τη χρήση της εφαρμογής.

### 5. 💬 Chat & Γρήγορες Απαντήσεις (Quick Replies)
- **Messaging:** Συνομιλία μεταξύ ηλικιωμένου και εθελοντή μέσα στο demo.
- **Quick Reply Chips:** Έτοιμα κουμπιά γρήγορων απαντήσεων (π.χ. *«Είμαι καθ' οδόν! 🚗»*, *«Έφτασα στην είσοδο»*) για ευκολία χρήσης.

### 6. ♿ Προσβασιμότητα & Έκτακτη Ανάγκη
- **Large Text Mode:** Διακόπτης μεγέθους γραμματοσειράς για πιο ξεκούραστη ανάγνωση.
- **Emergency SOS Modal:** Κουμπί που εμφανίζει παράθυρο επιβεβαίωσης για έκτακτη ανάγκη.
- **Star Rating:** Βαθμολόγηση της βοήθειας μετά την ολοκλήρωση της επίσκεψης.

> **Σημείωση για το prototype:** Η εφαρμογή είναι διαδραστικό front-end demo. Τα αιτήματα, οι συνομιλίες και οι αλλαγές κατάστασης αποθηκεύονται προσωρινά στη μνήμη της εφαρμογής και δεν συγχρονίζονται μεταξύ διαφορετικών συσκευών ή πραγματικών χρηστών. Οι προτάσεις και η λειτουργία SOS είναι ενδεικτικές και δεν συνδέονται με εξωτερική υπηρεσία ή υπηρεσίες έκτακτης ανάγκης.

## 🚀 Οδηγίες Εκτέλεσης (Quick Start)

### Εκτέλεση από τον καθηγητή

1. Εγκαταστήστε το **Node.js 20.19+** (ή **22.12+**) και το npm.
2. Κλωνοποιήστε το repository και μεταβείτε στον φάκελό του:

   ```bash
   git clone https://github.com/giorgostsrr-eng/-51.git
   cd -51
   ```

3. Εγκαταστήστε τις εξαρτήσεις και ξεκινήστε τον development server:

   ```bash
   npm install
   npm run dev
   ```

4. Ανοίξτε στον browser τη διεύθυνση που εμφανίζει το Vite στο terminal (συνήθως `http://localhost:5173`).
5. Για να σταματήσετε την εφαρμογή, πατήστε `Ctrl+C` στο terminal.

### Εκτέλεση σε GitHub Codespaces

Ανοίξτε το repository στο GitHub, επιλέξτε **Code → Codespaces → Create codespace**, και εκτελέστε στο terminal:

```bash
npm install
npm run dev
```

Όταν εμφανιστεί σχετική ειδοποίηση, επιλέξτε το προωθημένο port για να ανοίξετε την εφαρμογή στον browser.
