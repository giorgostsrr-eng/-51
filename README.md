# CareBridge (Ομάδα 51) 🤝

Μια εφαρμογή κοινοτικής φροντίδας (mobile-first prototype) που συνδέει ηλικιωμένους με εθελοντές φοιτητές για καθημερινή βοήθεια, συνοδεία και συντροφικότητα.

## Χαρακτηριστικά (Features)
- **Εναλλαγή Ρόλων:** Πλήρης υποστήριξη Senior View & Student Assistant View.
- **2-Step Booking Wizard:** Επιλογή υπηρεσίας, οριζόντιο διαδραστικό ημερολόγιο (Date Strip) και επιλογή ώρας.
- **Smart Feed & AI Ranking:** Κατάταξη αιτημάτων για τους φοιτητές με βάση απόσταση & δεξιότητες ("Best Choice").
- **Request Details Modal:** Προεπισκόπηση λεπτομερειών αιτήματος πριν την αποδοχή.
- **Live Progress Tracker:** Ζωντανή μπάρα προόδου επίσκεψης (Requested ➔ Student Found ➔ On the way 🚗 ➔ Done).
- **Interactive Chat:** Συνομιλία με έτοιμες γρήγορες απαντήσεις (Quick Replies).
- **Προσβασιμότητα:** Large Text Mode για ηλικιωμένους και κουμπί SOS.
